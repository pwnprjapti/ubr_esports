## 🛠️ Technology Stack Specs

The application uses a modern, robust, and lightweight JavaScript stack:
- **Frontend:** EJS (Embedded JavaScript), CSS3 (Custom Responsive Layouts), FontAwesome
- **Backend:** Node.js, Express.js (MVC architectural pattern)
- **Database:** MongoDB Atlas, Mongoose ODM
- **Storage:** Cloudinary API (Secure image hosting for proof of payments, QR codes, logos)
- **Auth:** Passport.js (Google OAuth 2.0 Strategy)

## ⏱️ Timeline & Milestones

The proposed delivery timeline is **20 Days** from project kickoff:
1. **Phase 1 (3 Days):** Setup, Schema Design, and Google OAuth Authentication.
2. **Phase 2 (5 Days):** Wallet ledger logic, image deposit approval system, and withdrawal requests.
3. **Phase 3 (4 Days):** Tournament category CRUD operations, match entries, and slot bookings.
4. **Phase 4 (5 Days):** Admin panel dashboard tables, transaction grids, and points table uploads.
5. **Phase 5 (3 Days):** System integration testing, Cloudinary configuration validation, and Live Launch.
